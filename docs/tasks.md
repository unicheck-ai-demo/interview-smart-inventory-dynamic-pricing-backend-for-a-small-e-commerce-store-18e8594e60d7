# Interview Tasks

## Task 1: Currency Conversion Calculation Error

When updating multi-currency prices for products, the system should calculate each currency's price by multiplying the product's base USD price by the given exchange rate. However, the values shown are unexpectedly off by a fixed amount rather than being proportional to the rate.

Please investigate and correct the calculation so that, for example, a base price of $10 with an exchange rate of 0.5 results in a price of 5 in that currency.
